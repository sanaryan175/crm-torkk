REQUIRED ENVIRONMENT VARIABLES
================================================================================

BACKEND (Render):
  NODE_ENV=production
  PORT=5000
  DATABASE_URL=postgresql://...  (Auto-injected by Render)
  JWT_SECRET=                     (Auto-generated by Render)
  JWT_EXPIRE=24h
  BREVO_API_KEY=xkeysib-...       (Get from Brevo)
  BREVO_SENDER_EMAIL=...          (Verified Brevo email)
  BREVO_SENDER_NAME=CRM Manager
  FRONTEND_URL=https://...        (Your Vercel URL)
  CORS_ORIGIN=https://...         (Same as FRONTEND_URL)

FRONTEND (Vercel):
  NEXT_PUBLIC_API_URL=https://...  (Your Render backend URL)

================================================================================
DEPLOYMENT STEPS OVERVIEW
================================================================================

1. Push to GitHub
   git push origin main

2. Create PostgreSQL Database on Render
   - Render Dashboard → New → PostgreSQL
   - Save Internal Connection String

3. Deploy Backend to Render
   - Render Dashboard → New Web Service
   - Connect GitHub repo
   - Root Directory: backend
   - Environment variables (see above)
   - Save Backend URL (https://crm-backend.onrender.com)

4. Deploy Frontend to Vercel
   - Vercel Dashboard → New Project
   - Import GitHub repo
   - Root Directory: frontend
   - Environment: NEXT_PUBLIC_API_URL = Backend URL
   - Save Frontend URL (https://yourapp.vercel.app)

5. Update Backend CORS
   - Update FRONTEND_URL and CORS_ORIGIN in Render
   - Use your Vercel URL
   - Redeploy backend

6. Configure Email (Brevo)
   - Sign up at Brevo
   - Verify sender email
   - Get API Key
   - Add to Render environment variables
