# Deployment Checklist

## Pre-Deployment

### Local Testing
- [ ] Backend builds successfully: `npm run build`
- [ ] Backend starts locally: `npm run dev`
- [ ] Frontend builds successfully: `npm run build`
- [ ] Frontend runs locally: `npm run dev`
- [ ] All tests pass: `npm test`
- [ ] No TypeScript errors
- [ ] No linting errors: `npm run lint`

### Code Preparation
- [ ] All code committed to Git
- [ ] `.env` files NOT in Git (check `.gitignore`)

### Accounts Created
- [ ] GitHub account (if not already)
- [ ] Render account (https://render.com)

## Backend Deployment (Render)

### Database Setup
- [ ] Go to: https://dashboard.render.com
- [ ] Click: "New +" → "PostgreSQL"
- [ ] Fill form:
  - [ ] Name: `crm-manager-db`
  - [ ] Database: `crm_manager`
  - [ ] User: `crm_user`
  - [ ] Region: Select closest to you
  - [ ] Plan: Free
- [ ] Click: "Create Database"
- [ ] Wait for database to be created (2-3 minutes)
- [ ] Copy **Internal Connection String** (save for later)
  - Should look like: `postgresql://crm_user:password@host:5432/crm_manager?schema=public`

### Web Service Setup
- [ ] Go to: https://dashboard.render.com
- [ ] Click: "New +" → "Web Service"
- [ ] Connect GitHub (if not already):
  - [ ] Click: "Connect account"
  - [ ] Authorize with GitHub
  - [ ] Select repository: `crm-manager`
- [ ] Configure service:
  - [ ] Name: `crm-backend`
  - [ ] Environment: `Node`
  - [ ] Region: Same as database
  - [ ] Branch: `main`
  - [ ] Root Directory: `.` (root)
  - [ ] Build Command: `npm install && npm run build && npx prisma generate`
  - [ ] Start Command: `npx prisma migrate deploy && node dist/server.js`
  - [ ] Plan: Free
- [ ] Click: "Create Web Service"
- [ ] Wait for deployment (5-10 minutes)

### Environment Variables (Backend)
- [ ] Go to backend service in Render
- [ ] Click: "Environment" tab
- [ ] Add these variables:

```
NODE_ENV = production
PORT = 5000
DATABASE_URL = <paste the Internal Connection String from step 1>
JWT_SECRET = <auto-generated or generate yourself>
JWT_EXPIRE = 24h
BREVO_API_KEY = <from Brevo account>
BREVO_SENDER_EMAIL = <your verified Brevo email>
BREVO_SENDER_NAME = CRM Manager
FRONTEND_URL = <will update later with Vercel URL>
CORS_ORIGIN = <will update later with Vercel URL>
```

- [ ] Click: "Save"
- [ ] Wait for auto-redeploy

### Verify Backend
- [ ] Get backend URL from Render (top of service page)
- [ ] Save it: `https://crm-backend.onrender.com`
- [ ] Test in browser: `https://crm-backend.onrender.com/api/health`
- [ ] Should see API response (no 404 error)

## Frontend Deployment (Vercel)

### Import Repository
- [ ] Go to: https://vercel.com/new
- [ ] Click: "Continue with GitHub"
- [ ] Authorize Vercel if needed
- [ ] Select repository: `crm-manager`
- [ ] Click: "Import"

### Configure Project
- [ ] Framework Preset: Next.js (auto-detect)
- [ ] Root Directory: `frontend` (click Edit if needed)
- [ ] Build Command: `npm run build`
- [ ] Output Directory: `.next`
- [ ] Node Version: Latest
- [ ] Do NOT add environment variables yet
- [ ] Click: "Deploy"
- [ ] Wait for deployment (5-10 minutes)

### Add Environment Variables
- [ ] Go to project in Vercel
- [ ] Click: "Settings"
- [ ] Click: "Environment Variables"
- [ ] Add variable:
  - Name: `NEXT_PUBLIC_API_URL`
  - Value: `https://crm-backend.onrender.com/api`
  - Environments: Production, Preview, Development
- [ ] Click: "Save"
- [ ] Vercel will auto-redeploy

### Get Frontend URL
- [ ] From Vercel project page, copy the URL
- [ ] Should look like: `https://crm-manager.vercel.app`
- [ ] Save it for next step

---

## Backend Update (CORS Configuration)

### Update FRONTEND_URL
- [ ] Go back to Render backend service
- [ ] Click: "Environment" tab
- [ ] Update `FRONTEND_URL`:
  - Old: (empty or placeholder)
  - New: `https://crm-manager.vercel.app` (your Vercel URL)
- [ ] Update `CORS_ORIGIN`:
  - Old: (empty or placeholder)
  - New: `https://crm-manager.vercel.app` (same as FRONTEND_URL)
- [ ] Click: "Save"
- [ ] Wait for auto-redeploy

## Email Service (Brevo)

### Create Brevo Account
- [ ] Go to: https://www.brevo.com
- [ ] Click: "Sign up"
- [ ] Complete registration

### Verify Sender Email
- [ ] Login to Brevo
- [ ] Go to: "Senders & lists"
- [ ] Add your email
- [ ] Click verification link in email

### Get API Key
- [ ] In Brevo, click your profile (top right)
- [ ] Click: "Settings"
- [ ] Click: "API Keys"
- [ ] Copy the API Key (starts with `xkeysib-`)

### Add to Render Backend
- [ ] Go to Render backend service
- [ ] Click: "Environment"
- [ ] Update these variables:
  - `BREVO_API_KEY`: `xkeysib-...` (paste from Brevo)
  - `BREVO_SENDER_EMAIL`: Your verified Brevo email
  - `BREVO_SENDER_NAME`: Your CRM name
- [ ] Click: "Save"
- [ ] Wait for auto-redeploy
